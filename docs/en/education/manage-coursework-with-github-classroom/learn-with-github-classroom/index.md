# Learn with GitHub Classroom

You can participate in coursework in GitHub Classroom and see results from your teacher.

## Links

* [View autograding results](/en/education/manage-coursework-with-github-classroom/learn-with-github-classroom/view-autograding-results)

  You can see results from autograding within the repository for your assignment.

* [Viewing your assignment's deadline](/en/education/manage-coursework-with-github-classroom/learn-with-github-classroom/viewing-your-assignments-deadline)

  You can view the deadline for an assignment at any time through the README of your assignment repository.
