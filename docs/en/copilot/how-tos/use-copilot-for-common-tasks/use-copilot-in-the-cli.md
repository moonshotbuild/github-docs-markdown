# Using the GitHub CLI Copilot extension

This article provides details about the replacement for the Copilot extension for GitHub CLI.

# Replacing the retired Copilot extension

The GitHub Copilot extension for GitHub CLI is retired. It has been replaced by the new GitHub Copilot CLI. See [About GitHub Copilot CLI](/en/copilot/concepts/agents/copilot-cli/about-copilot-cli).
