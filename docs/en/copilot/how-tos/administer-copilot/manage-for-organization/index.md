# Managing GitHub Copilot in your organization

Organization owners can subscribe to Copilot, manage Copilot for their organization, and control Copilot policies.

## Links

* [Managing the GitHub Copilot plan for your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-plan)

  Organization owners can manage the Copilot plan for their organization.

* [Managing access to GitHub Copilot in your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-access)

  Organization owners can grant and revoke Copilot access for members of their organization.

* [Managing policies and features for GitHub Copilot in your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-policies)

  Control the availability of GitHub Copilot features and models for users granted a license by your organization.

* [Adding GitHub Copilot cloud agent to your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/add-copilot-cloud-agent)

  Enable Copilot cloud agent for your members and control the repositories where it is available.

* [Configuring runners for GitHub Copilot cloud agent in your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/configure-runner-for-coding-agent)

  Configure the GitHub Actions runners used by Copilot cloud agent and control whether repositories can customize the runner type.

* [Preparing to use custom agents in your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/prepare-for-custom-agents)

  Configure the repository that stores custom agents for your organization.

* [Managing the availability of models in an organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-default-models)

  Configure which default Copilot models are available to members of your organization.

* [Reviewing activity related to GitHub Copilot in your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/review-activity)

  Organization owners can review Copilot usage in their organization.

* [Enabling custom models for GitHub Copilot in your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/enable-custom-models)

  Integrate your preferred custom models with GitHub Copilot by using your own LLM API keys, and make them available to your organization members.
