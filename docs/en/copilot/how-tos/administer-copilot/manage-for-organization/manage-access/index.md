# Managing access to GitHub Copilot in your organization

Organization owners can grant and revoke Copilot access for members of their organization.

## Links

* [Granting access to GitHub Copilot for members of your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-access/grant-access)

  Grant access to GitHub Copilot for some or all of the members of your organization.

* [Managing requests for GitHub Copilot Business in your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-access/manage-requests-for-access)

  Approve or deny requests for Copilot access in your organization.

* [Revoking access to GitHub Copilot for members of your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-access/revoke-access)

  Remove access to GitHub Copilot for some or all of the members of your organization.

* [Managing GitHub Copilot access to your organization's network](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-access/manage-network-access)

  Learn how to use subscription-based network routing to control Copilot access to your network.
