# Subscribing to GitHub Copilot for your organization

Organization owners can set up a Copilot Business plan for their organization.

> \[!NOTE]
> If your organization is part of an enterprise, you will gain Copilot through your enterprise instead. See [Subscribing to GitHub Copilot for your enterprise](/en/copilot/how-tos/administer-copilot/manage-for-enterprise/manage-plan/subscribe) and [Granting users access to GitHub Copilot in your enterprise](/en/copilot/how-tos/administer-copilot/manage-for-enterprise/manage-access/grant-access).

1. Navigate to the [GitHub Copilot sign up page](https://github.com/github-copilot/purchase?ref_product=copilot\&ref_type=purchase\&ref_style=text).
2. Ensure you are signed in to the right organization account. If you are not, click **<svg version="1.1" width="16" height="16" viewBox="0 0 16 16" class="octicon octicon-arrow-switch" aria-label="arrow-switch" role="img"><path d="M5.22 14.78a.75.75 0 0 0 1.06-1.06L4.56 12h8.69a.75.75 0 0 0 0-1.5H4.56l1.72-1.72a.75.75 0 0 0-1.06-1.06l-3 3a.75.75 0 0 0 0 1.06l3 3Zm5.56-6.5a.75.75 0 1 1-1.06-1.06l1.72-1.72H2.75a.75.75 0 0 1 0-1.5h8.69L9.72 2.28a.75.75 0 0 1 1.06-1.06l3 3a.75.75 0 0 1 0 1.06l-3 3Z"></path></svg> Switch** and select the organization for which you want to purchase GitHub Copilot.
3. Click **Enable GitHub Copilot**.
4. Enable Copilot for some or all members of your organization. For more information about assigning seats, see [Granting access to GitHub Copilot for members of your organization](/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-access/grant-access).
