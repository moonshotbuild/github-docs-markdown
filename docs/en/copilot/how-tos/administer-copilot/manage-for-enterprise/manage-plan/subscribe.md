# Subscribing to GitHub Copilot for your enterprise

Enterprise owners can set up a Copilot Enterprise or Copilot Business plan for their enterprise.

## Paying by credit card or PayPal

> \[!NOTE] If you are currently in a trial of GitHub Enterprise Cloud, you must convert to a paid enterprise before you can purchase GitHub Copilot.

1. Ensure you are signed in as an enterprise admin on GitHub.
2. Navigate to the [GitHub Copilot sign up page](https://github.com/github-copilot/purchase?ref_product=copilot\&ref_type=purchase\&ref_style=button\&ref_plan=enterprise).
3. Ensure you are making changes to the right enterprise account. If you are not, click **<svg version="1.1" width="16" height="16" viewBox="0 0 16 16" class="octicon octicon-arrow-switch" aria-label="arrow-switch" role="img"><path d="M5.22 14.78a.75.75 0 0 0 1.06-1.06L4.56 12h8.69a.75.75 0 0 0 0-1.5H4.56l1.72-1.72a.75.75 0 0 0-1.06-1.06l-3 3a.75.75 0 0 0 0 1.06l3 3Zm5.56-6.5a.75.75 0 1 1-1.06-1.06l1.72-1.72H2.75a.75.75 0 0 1 0-1.5h8.69L9.72 2.28a.75.75 0 0 1 1.06-1.06l3 3a.75.75 0 0 1 0 1.06l-3 3Z"></path></svg> Switch** and select the enterprise for which you want to purchase GitHub Copilot. You can also append `&enterprise=YOUR-ENTERPRISE` to the URL to pre-select the enterprise.
4. Follow the steps to sign up and enable Copilot for organizations in your enterprise. If you purchased Copilot Enterprise, you will be able to assign either Copilot Enterprise or Copilot Business to each individual organization in the enterprise.

## Other payment methods

> \[!NOTE]
> If you're under a Microsoft Enterprise Agreement, you need to connect your Azure subscription ID to your enterprise account to enable and pay for GitHub Copilot. For more information, see [Connecting an Azure subscription](/en/billing/how-tos/set-up-payment/connect-azure-sub).

1. To purchase GitHub Copilot for your enterprise, [contact GitHub's Sales team](https://github.com/enterprise/contact?ref_product=copilot\&ref_type=engagement\&ref_style=text).
2. A member of the Sales team will work with you to set up Copilot for your enterprise.
