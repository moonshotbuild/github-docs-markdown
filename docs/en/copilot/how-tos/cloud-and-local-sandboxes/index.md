# Cloud and local sandboxes for GitHub Copilot

Manage cloud and local sandboxes for GitHub Copilot for your organization.

## Links

* [Enabling or disabling cloud sandboxes for your organization](/en/copilot/how-tos/cloud-and-local-sandboxes/enabling-or-disabling-cloud-sandboxes-for-your-organization)

  You can control whether members of your organization can use cloud sandboxes by managing the sandbox access policy in your organization settings.

* [Configuring local sandbox settings](/en/copilot/how-tos/cloud-and-local-sandboxes/configuring-local-sandbox-settings)

  Use the /sandbox slash command in Copilot CLI to control how the local sandbox restricts filesystem access, network connectivity, and system capabilities.
