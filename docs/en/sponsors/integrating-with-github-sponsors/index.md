# Integrating with GitHub Sponsors

As an open source contributor, you can build custom tools to manage your GitHub sponsorships.

## Links

* [Configuring webhooks for events in your sponsored account](/en/sponsors/integrating-with-github-sponsors/configuring-webhooks-for-events-in-your-sponsored-account)

  You can configure webhooks to alert you when you receive new sponsorships or existing sponsors make changes to their sponsorships.

* [Getting started with the Sponsors GraphQL API](/en/sponsors/integrating-with-github-sponsors/getting-started-with-the-sponsors-graphql-api)

  Using the GraphQL API, you can build custom integrations to manage or review your sponsorships.
