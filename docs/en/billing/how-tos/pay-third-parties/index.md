# Making payments to third-parties through GitHub

You can upgrade, downgrade, or cancel GitHub Marketplace apps and sponsorships.

* [Downgrading the billing plan for a GitHub Marketplace app](/en/billing/how-tos/pay-third-parties/downgrade-marketplace-app)

  If you'd like to use a different billing plan, you can downgrade your GitHub Marketplace app at any time.

* [Canceling a GitHub Marketplace app](/en/billing/how-tos/pay-third-parties/cancel-marketplace-app)

  You can upgrade your sponsorship to a higher tier.

* [Downgrading a sponsorship](/en/billing/how-tos/pay-third-parties/downgrade-sponsorship)

  You can downgrade your sponsorship to a lower tier.

* [Canceling a sponsorship](/en/billing/how-tos/pay-third-parties/cancel-sponsorship)

  You can cancel your sponsorship.

* [Setting an end date to a sponsorship](/en/billing/how-tos/pay-third-parties/end-sponsorship)

  You can set an end date to an existing or new sponsorship.
