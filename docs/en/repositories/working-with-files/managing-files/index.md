# Managing files

You can create, edit, move, and delete files in a repository, directly on GitHub or on the command line.

## Links

* [Creating new files](/en/repositories/working-with-files/managing-files/creating-new-files)

  You can create new files directly on GitHub in any repository you have write access to.

* [Adding a file to a repository](/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

  You can upload and commit an existing file to a repository on GitHub or by using the command line.

* [Moving a file to a new location](/en/repositories/working-with-files/managing-files/moving-a-file-to-a-new-location)

  You can move a file to a different directory on GitHub or by using the command line.

* [Editing files](/en/repositories/working-with-files/managing-files/editing-files)

  You can edit files directly on GitHub in any of your repositories using the file editor.

* [Renaming a file](/en/repositories/working-with-files/managing-files/renaming-a-file)

  You can rename any file in your repository directly in GitHub or by using the command line.

* [Deleting files in a repository](/en/repositories/working-with-files/managing-files/deleting-files-in-a-repository)

  You can delete an individual file or an entire directory in your repository on GitHub.

* [Customizing how changed files appear on GitHub](/en/repositories/working-with-files/managing-files/customizing-how-changed-files-appear-on-github)

  To keep certain files from displaying in diffs by default, or counting toward the repository language, you can mark them with the linguist-generated attribute in a .gitattributes file.
