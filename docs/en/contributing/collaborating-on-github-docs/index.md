# Collaborating on GitHub Docs

Find out about collaborating on GitHub Docs.

## Links

* [About contributing to GitHub Docs](/en/contributing/collaborating-on-github-docs/about-contributing-to-github-docs)

  You can contribute to GitHub Docs content in several ways.

* [Using Git on GitHub Docs](/en/contributing/collaborating-on-github-docs/using-git-on-github-docs)

  You can use Git on the command line to commit changes and then push them to the documentation repository.

* [Using the TODOCS placeholder to leave notes](/en/contributing/collaborating-on-github-docs/using-the-todocs-placeholder-to-leave-notes)

  You can use the TODOCS placeholder to indicate work that still needs to be completed.

* [Using the content linter](/en/contributing/collaborating-on-github-docs/using-the-content-linter)

  You can use content linter to check your contributions for errors.

* [Label reference](/en/contributing/collaborating-on-github-docs/label-reference)

  Labels can help you find an issue you'd like to help with.
